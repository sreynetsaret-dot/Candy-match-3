# Candy Match 3

A mobile-friendly, installable Match-3 puzzle game.

## Deploy with Cloudflare Pages
1. In Cloudflare, open **Workers & Pages**.
2. Create a Pages project and connect this GitHub repository: `sreynetsaret-dot/Candy-match-3`.
3. Choose **main** as the production branch.
4. For a plain static site, leave the build command empty and set the build output directory to `/` (or `.`, depending on the dashboard).
5. Deploy. The game is served from `index.html`.

## Install on iPhone
Open the deployed HTTPS URL in Safari, tap Share, then **Add to Home Screen**.

The game runs locally in the browser. Scores are temporary for the current session; there are no cash prizes or real-money features.
